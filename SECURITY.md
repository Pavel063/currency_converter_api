# Security notes

| Уязвимость | CWE | Endpoint | Причина | Исправление |
|---|---|---|---|---|
| SQL Injection | CWE-89 | `/vulnerable/search` | Конкатенация пользовательского ввода с SQL | Параметризованные запросы |
| Reflected XSS | CWE-79 | `/vulnerable/greet` | Пользовательский ввод вставляется в HTML без экранирования | Контекстное HTML-экранирование |
| IDOR / Broken Access Control | CWE-639 | `/vulnerable/history/<id>` | Нет проверки владельца записи | Аутентификация + проверка прав |

Основная функция `/convert` получает курс только с внешнего API и использует параметризованный SQL-запрос для сохранения истории.
